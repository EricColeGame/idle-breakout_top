Les retours d'expérience de la communauté soulignent l'efficacité redoutable de la combinaison entre **Balles de poison** et **Balles à dispersion**. ## Dépannage des problèmes courants liés aux codes de sauvegarde

Même si la manipulation de chaînes de sauvegarde est généralement sûre, des erreurs imprévues peuvent survenir. Des caractères manquants, des restrictions de sécurité du navigateur ou des conflits de stockage peuvent figer le jeu ou afficher un écran totalement blanc au lancement.

```
Code saisi ──> Vérification du texte ──> Écriture LocalStorage ──> Affichage écran
                     │ (Échec)
                     └──> Écran blanc / Blocage infini
```

### Tableau de diagnostic et de résolution rapide

| Symptôme | Cause probable | Solution recommandée |
| :--- | :--- | :--- |
| **Écran blanc au chargement** | Chaîne de code incomplète ou erreur de formatage | Vider les cookies/le cache du site dans le navigateur, puis réimporter un code valide. |
| **Message « Invalid Code »** | Espace superflu ou caractères base64 corrompus | Copier d'abord la chaîne dans le Bloc-notes pour vérifier l'absence d'espaces au début ou à la fin. |
| **Jeu figé / 0 FPS** | La sauvegarde contient un nombre excessif de balles actives | Fermer les onglets en arrière-plan, désactiver temporairement l'accélération matérielle ou utiliser un code avec moins de balles. |
| **La progression disparaît à l'actualisation** | Navigation privée ou blocage du LocalStorage | Autoriser les cookies locaux et les données de site dans les paramètres de votre navigateur. |

Si vous rencontrez un plantage irrécupérable après avoir importé un code personnalisé, vider le cache spécifique au site réinitialisera le jeu à son état d'origine, vous permettant de coller une nouvelle chaîne saine.

## Foire aux questions sur les codes Idle Breakout

### Les codes Idle Breakout sont-ils des codes de triche officiels des développeurs ?
Non, le jeu ne propose pas de système d'échange de codes promotionnels ou de triche traditionnel. Ce que la communauté appelle **codes idle breakout** correspond en réalité à des chaînes de sauvegarde encodées en base64 générées par l'option Export intégrée au jeu.

### L'utilisation de codes d'importation peut-elle endommager ou corrompre ma partie ?
Oui, coller un code endommagé, tronqué ou surchargé d'entités peut bloquer le jeu, faire chuter le taux d'images par seconde ou causer un écran blanc. Exportez et sauvegardez toujours votre progression actuelle dans un fichier texte séparé avant d'importer de nouvelles données.

### L'importation d'un code fonctionne-t-elle sur les différents sites hébergeant le jeu ?
Dans la grande majorité des cas, oui. Comme la plupart des portails hébergent la même version WebGL ou HTML5 du jeu, les chaînes de sauvegarde créées sur un site peuvent être importées sans problème sur un autre.

### Comment réinitialiser complètement le jeu si un code importé bloque l'onglet ?
Si votre jeu refuse de se charger après un import, ouvrez les paramètres de votre navigateur, allez dans Données de sites / Cookies, recherchez l'adresse hébergeant le jeu et effacez les données locales de cette page. Cela supprimera la sauvegarde corrompue et vous permettra de repartir à zéro.
