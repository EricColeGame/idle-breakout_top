## Browser Mechanics, Local Storage, and Save Protection

Because the title runs inside client-side JavaScript, your progression lives almost exclusively within your browser's `localStorage` or index cache. A single accidental sweep from an automated cleaning tool, browser privacy extension, or incognito window can erase your progress instantly.

Community reports frequently highlight players losing weeks of prestige progress simply because their browser automatically purged temporary site data during an update. To prevent this, you must treat your export code as your primary cloud save.

### Understanding Export and Import Save Strings

The game includes a built-in import/export tool located in the settings menu. Clicking "Export" generates a long alphanumeric Base64 string that encodes your current level, unlocked balls, click upgrades, and prestige points. 

```text
Example format:

```

* **Copy weekly backups:** Paste your export string into a secure text document, notes app, or private cloud drive.
* **Keep milestone copies:** Always copy a new save string immediately before spending large amounts of prestige currency or starting a fresh reset.
* **Avoid altered strings:** Modifying individual characters in an export code can corrupt the file structure, causing the web loader to freeze on initial boot.

## Frequently Asked Questions About Idle Breakout Online

### Can I transfer my progress in idle breakout online between different computers?
Yes, you can easily transfer progress between machines using the game's built-in export tool. Open the settings panel in your current game session, click "Export," and copy the generated text string. On your new computer, open the game on any compatible web host, select "Import" inside the settings menu, paste the string, and confirm. Your exact level, balls, and prestige upgrades will transfer immediately without requiring an account login.

### Why did my save file disappear after restarting my computer?
Save data for web games is stored directly in your browser's local cache. If your browser is set to automatically clear cookies, cache, or site data upon closing, your game data is deleted alongside it. Additionally, playing in Incognito or Private browsing modes creates temporary sandboxes that erase all data the moment the window closes. Always keep manual text copies of your export code to prevent unexpected data loss.

### Can I run idle breakout online in a minimized background tab?
While you can leave the game running in the background, most modern web browsers will automatically throttle background tabs to save system memory and battery. This throttling drastically reduces game calculation speed. To maintain full gold and clear rates while away, keep the game running in its own dedicated, un-minimized browser window, or disable background tab throttling in your browser's advanced flag settings.

### What is the fastest ball build for early game progression?
For the earliest stages (levels 1 through 100), the most efficient path is prioritizing Basic Ball speed upgrades combined with a single Plasma Ball to handle dense clusters. Avoid purchasing high-cost specialized balls until your baseline income allows you to immediately upgrade their speed; an un-upgraded late-tier ball moves too slowly to justify its purchase cost in early stages.
