## Troubleshooting Common Issues with Save Codes

While working with save strings is generally safe, unexpected errors can occur. Missing characters, browser security flags, and conflicting storage entries can cause your screen to go completely white or freeze on launch.

```
Input Code ──> String Check ──> LocalStorage Write ──> Screen Render
                     │ (Failure)
                     └──> White Screen / Infinite Freeze
```

### Quick Diagnostic and Resolution Table

| Symptom | Probable Cause | Recommended Fix |
| :--- | :--- | :--- |
| **White Screen on Load** | Incomplete code string or formatting error | Clear browser cookies/cache for that site, then re-import a clean code. |
| **"Invalid Code" Prompt** | Trailing whitespace or broken base64 characters | Re-copy string into Notepad first, ensure no accidental space at front or back. |
| **Game Unresponsive / 0 FPS** | Save string contains an excessive number of active balls | Close running background tabs, disable hardware acceleration briefly, or use a lower ball count save. |
| **Progress Reverts on Refresh** | Browser running in Incognito or blocking LocalStorage | Enable local cookies and site storage permissions in your browser settings. |

If you ever encounter an unrecoverable crash after importing a custom code string, clearing your browser’s site-specific cache for that domain will return the game to factory settings, allowing you to paste a clean string safely.

## Frequently Asked Questions About Idle Breakout Codes

### Are idle breakout codes official developer cheat codes?
No, the game does not feature a traditional promo or cheat code redemption box. What the community calls **idle breakout codes** are actually base64-encoded save-state strings generated through the game's built-in Export feature.

### Can using import codes break or corrupt my game?
Yes, pasting a damaged, truncated, or excessively bloated save code can cause the game to freeze, drop frame rates, or display a blank white screen. Always export and back up your current progress into a separate text file before importing new data.

### Will importing a save code work across different browser gaming sites?
In almost all cases, yes. Because most host websites host the identical WebGL or HTML5 build of the game, save strings generated on one portal can be imported successfully into another.

### How do I reset my game completely if an imported code freezes the tab?
If your game will not load after an import, open your browser settings, navigate to Site Data / Cookies, search for the website hosting the game, and clear the local storage for that page. This clears the broken save and lets you start fresh.
